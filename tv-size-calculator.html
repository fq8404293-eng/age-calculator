How TV Size Is Calculated

Television sizes are measured diagonally from one corner of the visible screen to the opposite corner.

Because most televisions use a 16:9 aspect ratio, the width and height can be calculated from the diagonal measurement.

Width = Diagonal × 16 ÷ √(16² + 9²)

Height = Diagonal × 9 ÷ √(16² + 9²)

The calculator also estimates viewing distance using common recommended ranges for comfortable television viewing.

Frequently Asked Questions

How is TV size measured?

TV size refers to the diagonal distance across the visible display, not the width of the television.

How wide is a 55-inch TV?

A standard 16:9 55-inch television has a screen width of about 47.9 inches.

Does the bezel count in TV size?

No. Television size usually refers only to the visible display, excluding the bezel and outer frame.

What is the best viewing distance for a TV?

The ideal distance depends on TV size, resolution and personal preference. Larger 4K televisions can often be viewed comfortably from closer distances than lower-resolution TVs.

Does resolution change the physical TV size?

No. Resolution changes the number of pixels on the screen but does not change the physical width or height of a television with the same diagonal size.

Can I calculate centimeters instead of inches?

Yes. Enter the TV diagonal in centimeters and the calculator will automatically provide both centimeter and inch measurements.
