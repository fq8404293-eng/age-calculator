What Is a Square Root?

The square root of a number is a value that, when multiplied by itself, produces the original number.

For example, the square root of 25 is 5 because 5 × 5 = 25.

The square root symbol is called the radical sign and is written as √.

Square Root Formula

If a number is represented by x, its square root can be written as:

√x = y

This means that:

y × y = x

For example:

√144 = 12

because 12 × 12 = 144.

Square Root Examples

Example 1: √100 = 10 because 10 × 10 = 100.

Example 2: √64 = 8 because 8 × 8 = 64.

Example 3: √2 ≈ 1.414213562 because 1.414213562 × 1.414213562 is approximately 2.

Not every positive number has a whole-number square root. The calculator displays an accurate decimal approximation for such numbers.

Important Note About Negative Numbers

This calculator is designed to calculate real-number square roots. A negative number does not have a real-number square root.

For example, √−9 is not a real number. It can be represented using imaginary numbers, but that is outside the scope of this calculator.

Frequently Asked Questions

What is the square root of 25?

The square root of 25 is 5 because 5 × 5 = 25.

What is the square root of 144?

The square root of 144 is 12 because 12 × 12 = 144.

Can I calculate the square root of a decimal?

Yes. You can enter decimal values such as 2.25, 10.5, or 0.25.

Can I calculate the square root of a negative number?

This calculator only provides real-number results, so negative inputs are not accepted.

What is a perfect square?

A perfect square is a number whose square root is a whole number. Examples include 4, 9, 16, 25, and 100.
