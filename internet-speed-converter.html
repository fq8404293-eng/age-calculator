Bits vs. Bytes

Internet service providers commonly advertise connection speeds in bits per second, such as Mbps or Gbps. Downloaded files are often displayed in bytes, such as MB or GB.

A byte contains eight bits. Therefore, converting from megabits per second to megabytes per second requires dividing by eight.

1 byte = 8 bits

MB/s = Mbps ÷ 8

Mbps = MB/s × 8

Internet Speed Conversion Formula

The calculator converts every speed into bits per second first. It then converts that value into the requested units.

1 Kbps = 1,000 bps

1 Mbps = 1,000,000 bps

1 Gbps = 1,000,000,000 bps

1 MB/s = 8 Mbps

This calculator uses decimal networking units, where each kilobit is 1,000 bits and each megabit is 1,000,000 bits.

Internet Speed Conversion Example

Suppose your internet plan provides a download speed of 100 Mbps.

Since one byte contains eight bits, divide 100 Mbps by 8:

100 Mbps ÷ 8 = 12.5 MB/s

Therefore, a perfect 100 Mbps connection could theoretically transfer about 12.5 megabytes per second before accounting for protocol overhead, network conditions and server limitations.

Why Actual Download Speeds Can Be Lower

The converted value represents the mathematical data rate. Real-world download speeds can be lower than the theoretical maximum.

Factor Possible Effect
Wi-Fi Conditions Signal strength and wireless interference can reduce speed.
Network Congestion Busy networks can reduce available bandwidth.
Server Limitations The remote server may not send data at your maximum speed.
Network Overhead Some bandwidth is used by communication protocols.
Other Devices Phones, computers, streaming devices and other equipment may share the connection.

Frequently Asked Questions

How many MB/s is 100 Mbps?

100 Mbps equals 12.5 MB/s because one byte contains eight bits.

How many Mbps is 1 Gbps?

Using decimal networking units, 1 Gbps equals 1,000 Mbps.

Is Mbps the same as MB/s?

No. Mbps means megabits per second, while MB/s means megabytes per second. One byte equals eight bits.

Why do internet companies use Mbps?

Internet connection speeds are commonly specified in bits per second because network data rates are traditionally measured using bits.

What is a good internet speed?

The appropriate speed depends on the number of users, devices and activities such as web browsing, video streaming, gaming and large downloads.

Does this calculator show my actual internet speed?

No. This is a unit converter, not an internet speed test. It converts a speed you provide between different measurement units.
