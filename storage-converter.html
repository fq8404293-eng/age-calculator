Decimal vs. Binary Storage Units

Digital storage can be expressed using decimal or binary units. Decimal units use powers of 1,000, while binary units use powers of 1,024.

Decimal Unit Decimal Value Binary Unit Binary Value
1 KB 1,000 bytes 1 KiB 1,024 bytes
1 MB 1,000,000 bytes 1 MiB 1,048,576 bytes
1 GB 1,000,000,000 bytes 1 GiB 1,073,741,824 bytes
1 TB 1,000,000,000,000 bytes 1 TiB 1,099,511,627,776 bytes

Storage Conversion Formula

The calculator first converts the entered value into bytes. It then converts the byte value into each supported storage unit.

1 KB = 1,000 bytes

1 MB = 1,000,000 bytes

1 GB = 1,000,000,000 bytes

1 KiB = 1,024 bytes

1 MiB = 1,048,576 bytes

1 GiB = 1,073,741,824 bytes

Storage Conversion Example

Suppose you have a storage device advertised as 5 GB.

Using decimal units, 5 GB equals:

5 GB = 5,000 MB

5 GB = 5,000,000 KB

5 GB = 5,000,000,000 bytes

The same number of bytes is approximately 4.66 GiB when expressed using binary gibibytes.

Why Storage Sizes Can Look Different

A storage device may be marketed using decimal units while an operating system may display capacity using binary-based calculations or different labeling conventions.

This can make a drive advertised as a certain number of gigabytes appear to have a different numerical capacity when viewed on a computer.

For example, a manufacturer using decimal units defines 1 GB as 1,000,000,000 bytes. A binary conversion expresses the same byte count as approximately 0.93 GiB.

Frequently Asked Questions

How many MB are in 1 GB?

Using decimal storage units, 1 GB equals 1,000 MB.

How many GB are in 1 TB?

Using decimal units, 1 TB equals 1,000 GB.

What is the difference between GB and GiB?

GB is a decimal unit based on powers of 1,000, while GiB is a binary unit based on powers of 1,024.

Is 1 GB equal to 1 GiB?

No. One GB contains 1,000,000,000 bytes, while one GiB contains 1,073,741,824 bytes.

Why does my hard drive show less space than advertised?

Storage manufacturers commonly use decimal units. The operating system may present the capacity using a different unit or convention, making the displayed number appear smaller.

What is the difference between MB and MiB?

MB is a decimal unit equal to 1,000,000 bytes, while MiB is a binary unit equal to 1,048,576 bytes.
