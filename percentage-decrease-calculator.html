How Percentage Decrease Is Calculated

Percentage decrease shows how much a value has fallen compared with its original value. It can be useful for comparing price reductions, discounts, changes in measurements, expenses, sales, and other numerical values.

The percentage decrease formula is:

Percentage Decrease = ((Original Value − New Value) ÷ Original Value) × 100

First, subtract the new value from the original value to find the amount of decrease. Then divide that amount by the original value and multiply by 100.

Percentage Decrease Example

Suppose a product originally costs $100 and its new price is $80.

Original Value 100
New Value 80
Decrease Amount 20
Percentage Decrease 20%

The value decreased by 20, which represents a 20% decrease from the original value of 100.

Common Uses for Percentage Decrease

Percentage decrease is useful whenever you need to understand how much a value has fallen relative to where it started.

  • Comparing original and discounted prices
  • Measuring reductions in expenses
  • Comparing changes in sales or revenue
  • Tracking decreases in measurements or quantities
  • Analyzing changes in budgets and costs

Frequently Asked Questions

How do you calculate percentage decrease?

Subtract the new value from the original value, divide the difference by the original value, and multiply by 100.

What is the percentage decrease from 100 to 80?

The decrease is 20. Since 20 is 20% of the original value of 100, the percentage decrease is 20%.

Can the percentage decrease be more than 100%?

When the original value is positive and the new value is zero or greater, the maximum percentage decrease is 100%.

What is the difference between percentage decrease and percentage points?

Percentage decrease measures relative reduction from the original value, while percentage points measure the direct difference between two percentages.
