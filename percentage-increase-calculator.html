How Percentage Increase Is Calculated

Percentage increase shows how much a value has grown compared with its original value. It is commonly used for prices, salaries, sales, population, measurements, and other numerical comparisons.

The percentage increase formula is:

Percentage Increase = ((New Value − Original Value) ÷ Original Value) × 100

First, subtract the original value from the new value to find the amount of increase. Then divide that increase by the original value and multiply by 100.

Percentage Increase Example

Suppose a product originally costs $100 and its new price is $125.

Calculation Result
Original Value 100
New Value 125
Increase Amount 25
Percentage Increase 25%

The value increased by 25, which represents a 25% increase from the original value of 100.

Percentage Increase vs. Percentage Decrease

Percentage increase is used when comparing a larger new value with an original value. If the new value is smaller than the original value, the same calculation produces a negative percentage, indicating a decrease.

Original New Percentage Change
100 125 25% increase
100 150 50% increase
100 80 20% decrease

Frequently Asked Questions

How do you calculate percentage increase?

Subtract the original value from the new value, divide the difference by the original value, and multiply by 100.

What is the percentage increase from 100 to 120?

The increase is 20. Since 20 is 20% of the original value of 100, the percentage increase is 20%.

Can percentage increase be negative?

Yes. When the new value is lower than the original value, the calculated percentage change is negative. This represents a percentage decrease.

What is the difference between percentage increase and percentage points?

Percentage increase measures relative change, while percentage points measure the direct difference between two percentages. For example, moving from 40% to 50% is a 10 percentage-point increase, but it is a 25% relative increase.
