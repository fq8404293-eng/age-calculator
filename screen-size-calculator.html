How Screen Size Is Calculated

Screen size is normally specified by the diagonal distance from one corner of the display to the opposite corner.

The physical width and height can be calculated when the diagonal measurement and aspect ratio are known.

Diagonal² = Width² + Height²

The aspect ratio determines the relationship between width and height.

For a 16:9 display, the screen is 16 units wide for every 9 units of height.

What Is Screen Aspect Ratio?

Aspect ratio describes the proportional relationship between a screen's width and height.

Aspect Ratio Common Use
16:9 Modern TVs, monitors and laptops
16:10 Many productivity monitors and laptops
21:9 Ultrawide monitors
32:9 Super-ultrawide displays
4:3 Older monitors and some specialized displays

Screen Size Example

Consider a 27-inch display with a 16:9 aspect ratio.

The diagonal is 27 inches, while the width-to-height relationship is 16 to 9.

The resulting physical dimensions are approximately 23.53 inches wide and 13.24 inches high.

This gives a screen area of approximately 311.5 square inches.

Screen Size and Pixel Density

Pixel density, commonly expressed as pixels per inch (PPI), describes how many pixels are packed into each inch of the display.

Two screens can have the same physical size but different resolutions. The higher-resolution screen will generally have greater pixel density.

If you enter both horizontal and vertical resolution, this calculator can estimate PPI using the calculated diagonal dimension.

Frequently Asked Questions

How is monitor size measured?

Monitor and television screen sizes are normally measured diagonally from one corner of the visible display to the opposite corner.

How wide is a 27-inch 16:9 monitor?

A 27-inch 16:9 display is approximately 23.53 inches wide and 13.24 inches high, excluding the bezel.

What is the most common screen aspect ratio?

16:9 is widely used for modern televisions, monitors, laptops and other consumer displays.

Does screen size include the bezel?

Screen size generally refers to the diagonal measurement of the display itself, not the external dimensions of the monitor or television housing.

What is PPI?

PPI means pixels per inch. It indicates the number of display pixels contained within each inch of the screen.

Can I use centimeters instead of inches?

Yes. Enter the diagonal in centimeters and the calculator will provide the equivalent dimensions in centimeters and inches.
