What Are Mean, Median, and Mode?

Mean, median, and mode are three common ways of describing the center or typical value of a dataset.

The mean is the arithmetic average of all values. The median is the middle value when the numbers are arranged in order. The mode is the value that occurs most frequently.

These measures can describe the same dataset in different ways, so looking at all three can provide a better understanding of the data.

What Is the Mean?

The mean is calculated by adding all values in a dataset and dividing the total by the number of values.

Mean = Sum of Values ÷ Number of Values

For example, for the numbers 10, 20, and 30:

Mean = (10 + 20 + 30) ÷ 3 = 20

What Is the Median?

The median is the middle value of a dataset after the numbers have been arranged from smallest to largest.

When there is an odd number of values, there is one middle value.

When there is an even number of values, the median is the average of the two middle values.

Odd example: 3, 5, 7, 9, 11

Median = 7

Even example: 3, 5, 7, 9

Median = (5 + 7) ÷ 2 = 6

What Is the Mode?

The mode is the value that appears most frequently in a dataset.

For example, in the dataset 2, 3, 3, 5, 7, the number 3 occurs twice, while the other values occur once. Therefore, the mode is 3.

A dataset can have one mode, multiple modes, or no mode when every value occurs with the same frequency.

Mean vs. Median vs. Mode

Measure Meaning How It Is Found
Mean Arithmetic average Sum ÷ Count
Median Middle value Arrange values and find the center
Mode Most frequent value Find the value appearing most often

Example: 2, 4, 4, 6, 8

Consider the dataset:

2, 4, 4, 6, 8

The sum is 24 and there are 5 values.

Mean = 24 ÷ 5 = 4.8

The middle value is 4, so:

Median = 4

The value 4 occurs twice, more often than any other value.

Mode = 4

What Is the Range?

The range describes the difference between the largest and smallest values in a dataset.

Range = Maximum Value − Minimum Value

For example, if the smallest value is 4 and the largest value is 18:

Range = 18 − 4 = 14

When Should You Use Mean, Median, or Mode?

The mean is useful when you want the arithmetic average and the values do not contain unusually influential extremes.

The median can be useful when a dataset contains unusually high or low values because it focuses on the middle position rather than adding every value together.

The mode is useful when you want to know which value occurs most frequently, especially when repeated values are important.

The best measure depends on the dataset and what you are trying to understand.

Frequently Asked Questions

What is the mean?

The mean is the sum of all values divided by the number of values.

What is the median?

The median is the middle value after a dataset is arranged from smallest to largest. With an even number of values, it is the average of the two middle values.

What is the mode?

The mode is the value or values that occur most frequently in a dataset.

Can a dataset have more than one mode?

Yes. If multiple values share the highest frequency, the dataset can have multiple modes.

Can a dataset have no mode?

Yes. If every value occurs the same number of times, there is no unique mode.

Does the mean have to be one of the values?

No. The mean can be a value that does not appear anywhere in the dataset.
